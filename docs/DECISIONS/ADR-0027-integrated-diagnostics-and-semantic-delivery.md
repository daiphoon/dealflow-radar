# ADR-0027：有效内容版本与远程诊断边界

- 状态：依据负责人 2026-09-24 对整合任务书 W01—W12 的本地实施授权；生产启用单独批准。
- 基线：`a42d13cc98d2e144b737709c266fe2066f6455f5`，原迁移 `0035`，开始时工作区干净。
- 保留 ADR-0021/0022/0025/0026、E4.10 及原 E4.9 线索 1/4、严格交付 0/4。

## 决定

1. 事项类型来自 `matter_contract`，生产与评估可使用相同 schema/提示/验证器；历史评估模式显式命名。正式请求上限为 4，旧输出仅在显式兼容入口容纳历史格式。数量受限不代表全文检查完成。
2. 来源版本哈希与保留表示哈希分开。共享抓取哈希不变，摘录或坐标不同则追加 RawDocument 表示，保持原文历史；不将公司 ID 混入源内容哈希。多窗口证据只能在单个连续保留窗口中成立。
3. 归并历史须匹配确切证据片段、当前 fact_version/processing_version、许可与哈希。旧观测继续保留，不能仅因为同文档还有另一条证据而复活。
4. 融资/退出查询按子问题有界轮换；子问题成功不刷新整个大类已查全状态。不开长期巡检，不改变任务调用上限。
5. 回访、巡检、报告复用共同采用获准有效内容的语义指纹。引文 ID、抓取时间、处理版本不单独产生业务变化。已确认回访不顺带扩大到候选；巡检内部可以比较已有获准候选的变化。
6. 新增迁移 `0036`：旧回执的历史内容未知，以迁移当下授权投影作为新基线，并保留原 first_seen_at。不宣称该基线是用户当时看到的版本；迁移之后的变化参与未读判断。新增报告请求映射保持复用后的客户端请求幂等。应用回退保留迁移及历史，避免删除新记录。
7. 新页面显式确认实际渲染的语义版本；V1 页面不能把并发 V2 标成已读。旧客户端按其收到的返回投影确认，兼容期保留。诊断入口完全不调用刷新、回访或报告写操作。
8. Diagnostic Service 为独立 PostgreSQL 视图读取层，CLI/MCP 为薄适配；首版默认仅 `public_metadata`，不开放原文摘录、私有持仓、任意 SQL、shell、文件和 URL。公开元数据进入外部模型仍属于外发，生产外发公司范围须批准。
9. MCP 账号无基础表权限、无角色继承/成员资格、非 owner/superuser/BYPASSRLS。视图采用 security_barrier；使用独立 NOLOGIN、非 owner 的视图所有者执行 RLS，客户端无权 SET ROLE 到该角色。所有者为既有 RLS 的关联查询保留只读表权限；对诊断数据表另施加作用域限制性策略。未粗暴撤销全库 PUBLIC 权限；原只读 SECURITY DEFINER 函数仍需在目标数据库中逐一复核。
10. 诊断与可选隧道客户端最终运行在远程服务器。Mac 经既有 Tailscale 做受限运维；ChatGPT 需独立受认证隧道路径。不开 Funnel、不要求客户使用 Tailscale、不公开 PostgreSQL。

工程测试、历史材料后处理、已知 URL 读取、维护、独立发现分别统计。本地离线工程不证明模型收益或真实召回。五项生产前提、官方文档核对、工作包交付与集中授权清单见 [18 整合交付](../18-integrated-delivery.md)。
