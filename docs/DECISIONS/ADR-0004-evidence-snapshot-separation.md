# ADR-0004：原始证据与派生快照分离

- 状态：已接受
- 日期：2026-07-13

## 背景

只保存 AI 摘要无法复核来源、纠错历史或重建报告；直接覆盖最新值会丢失未上市公司稀缺的历史观测。

## 决定

分开保存来源/原始文档、实体提及、事件及证据、指标观测、审核记录、公司快照和报告。已发布事件至少关联一条证据；原始事实追加保存，纠错和撤回保留版本；快照与报告带事实水位且可重建。

## 影响

存储和查询关系稍多，但证据、时间语义和生成过程可追溯。普通新闻只保存许可允许的最小片段，避免以“可追溯”为由无边界保存全文。详见[数据库设计](../03-database-design.md)。
