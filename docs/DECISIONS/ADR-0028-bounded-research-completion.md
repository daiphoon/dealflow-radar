# ADR-0028：有界研究完成状态与如实报告

- 状态：依据负责人 M2-R 本地工程及隔离网络验证授权；合并、部署、真实研究及自动巡检另行批准。
- 基线：main `7a61807dc284d22252d2f7dfcbf351f26fa90d6c`。
- 保留 ADR-0022/0025/0026/0027 的人工资料、事项、证据、语义版本及权限规则；上一轮 M2 `PARTIAL / FAIL`、严格召回 `0/8` 原封存保留，旧九家公司只作回归。

## 决定

1. 同一个正式 `TrustedSourceFetcher` 检查所有运行环境。计量 Provider 调用之前，固定三个普通 HTTPS 目标先验证 DNS、TLS、connected peer、DNS rebinding、逐跳 redirect 及 robots。所有解析地址必须是允许的公网地址；混合地址、`198.18/15`、不可验证 peer 等继续拒绝。预检没有 Provider、模型或数据库依赖，不保存正文。
2. 预检最多 12 次 HTTP、256,000 字节、每响应 64,000 字节、每请求 5 秒、无重试、每目标至多两跳 redirect。成功仅可在同一 Worker 进程复用五分钟；进程或时间变化后重新验证。失败保留结构化环境终态，不进入计量阶段，退回未使用的个人研究额度，已有资料继续可读。请求频率限制仍生效。
3. 用户主动更新为 `bounded_full_scope_refresh`：八类都进入计划并分别记录 `completed / partial / failed / budget_deferred / not_run`。整体为 `complete / partial / failed / not_run`，只有八类均完成有限检查时才是 `complete`。一次任务结束、已有事实、已成功搜索或只检查子问题，均不等于整家公司查全。
4. 继续使用已有 JSON coverage，不增加迁移。完成状态、用户投影、报告、每类成功检查时间和巡检成功判断使用同一投影。旧任务按原冻结计划恢复，不虚构其他类别已完成；已有文档但没有旧类别记录的任务可说明处理过资料，不能反推其研究范围。
5. 主动更新按最近尝试的类别轮换起点；正文候选仍按现有类别公平轮转。单类失败不删除其他类结果。默认上限保持搜索 4、HTTP 8、2MB、3 份正文、模型 3 次、每次输入 16k/输出 2k、执行 180 秒；金额、公司/租户/系统闸门仍按已有配置。预算不足的类别必须如实延期，不自动提高预算。四次搜索通常不能完成八类，产品不得承诺每次更新必定查全。
6. Watchlist 保留已有三个主题的低成本检查与关闭状态，不能以一次有限轮换刷新全公司。成功时间只来自实际完成的来源检查；缓存沿用原来源时间，失败/必要 fallback 未完成不刷新成功时间。
7. 新报告模板 `personal-company-v4` 明确呈现研究状态、八类覆盖、近期确认资料、窗口外历史、获准未确认线索及信息缺口。月/年等精度保守处理；未知不是无变化。历史报告不重建，原 v3 的许可保护保持。
8. v4 的 lead 引用在已有 JSON 中保存身份与 `unconfirmed_lead` 类型，读取时重新验证状态和许可；撤回、晋升或撤权后限制原正文，不因只保存 UUID 而失去类型保护。API 仍输出 UUID 列表。允许展示线索不改变 Event、confidence、snapshot 或发布状态。
9. 失败审计只保留 hostname、类别、URL 哈希、地址安全分类/哈希、dispatch/HTTP、时间和获取状态。普通用户只见六种抽象失败类别，不输出地址、stack、认证、内部路径或数据库细节。
10. 本地 fake-IP 环境用于 Mock、隔离 PostgreSQL、离线回归；香港正式预检通过只能证明未来 Runner 的网络能力。真实业务质量、Worker 部署、权限和成本批准仍是独立闸门，不自动开启运行。

## 验收与限制

行为级失败回归、网络安全矩阵、正常八类任务、冻结旧计划、Watchlist、十四类报告及正式 curated 维护入口分别验证。真实候选代码在香港隔离容器只访问固定免费目标；没有生产数据库或用户挂载。

维护按正式 `CuratedWorkbookProvider` 的稳定记录 ID 与负责人决定追加版本；同事项补证、纠正和日期补强不重建事项，旧证据/观测保留。待核表没有确认字段，单改说明或附强证据不自动晋升；也不把人工指定新记录 ID 的阶段维护说成已证明自动跨阶段归并。

统一交付与下一闸门见 [M2-R 交付说明](../24-m2-r-truthful-delivery.md)。本轮没有新留出成绩，网络与报告验收不等于召回通过。
