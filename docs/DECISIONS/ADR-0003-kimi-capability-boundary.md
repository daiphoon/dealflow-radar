# ADR-0003：Kimi 产品能力与应用 API 解耦

- 状态：已接受
- 日期：2026-07-13

## 背景

Kimi 消费端会员、Agent、Work/Claw、Kimi Code、开放平台 API 和专业商业数据库具有不同授权与计费边界。把会员能力视为网站后台 API 会带来稳定性、合规和再分发风险。

## 决定

系统不依赖 Kimi 也能运行。消费端/Agent 结果只经人工或官方导出导入候选层；开放平台只有在正式 API、价格和条款确认后才能作为 Provider；商业数据库必须单独授权。禁止未公开接口、账户页面抓取、Cookie 保存和绕过限流。Kimi Code 只视为开发辅助，不视为数据或生产 API 授权。

## 影响

短期需要人工导入，自动化较少；换来清晰的数据血缘、许可与供应商独立性。具体格式和启用条件见[数据源策略](../05-data-source-strategy.md)。
