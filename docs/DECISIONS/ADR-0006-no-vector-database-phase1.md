# ADR-0006：第一阶段不使用独立向量数据库

- 状态：已接受
- 日期：2026-07-13

## 背景

当前核心任务是结构化事件、证据、指标和固定页面，不是对全部历史文档做自然语言问答。独立向量库会增加索引、权限同步、删除和运维成本。

## 决定

第一阶段不引入独立向量数据库。身份、文档和事件检索先使用确定性字段、规范别名、元数据、索引及必要时 PostgreSQL 全文检索；不为未来可能需求预建嵌入流水线。

## 影响与重审条件

短期架构更简单，证据定位更确定。只有出现经过验证的跨大量授权文档语义检索用例，且关键词/元数据/PostgreSQL 全文检索未达到召回验收值，同时权限与删除方案明确时，才用新 ADR 评估向量能力。
