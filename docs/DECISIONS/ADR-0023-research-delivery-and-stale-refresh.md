# ADR-0023：多维资料接收、研究闭环与过期访问更新

- 状态：2026-09-20 负责人批准执行；实施进度以看板为准。
- 补充 ADR-0021/0022；取代 E4.6 后仅修排序的下一切片，不重开已验收的基础设施。

## 决定

1. 固定工作范式：负责人取得公司名单，调研最近三年多维重要信息并复核，提供表格；系统轻量校验、预览和导入，后续按需补充、更正并保留版本。更早且仍有效的事项保留。25 家现有资料足以开工，109 家不是前置条件；后续批次增补，不重建数据库。资料库持续更新，当次验收基准单独冻结。
2. 八类业务信息均支持人工接收和基础发现：经营财务、融资股权、合同商业、产品技术、治理人员、司法合规、产能资产、退出进程。信息质量贯穿各类。融资/IPO 优先做深不等于排除其他类别；缺真实样本的类别不得声称已通过真实价值验收。
3. 用户查询立即返回已有数据。超过保鲜期时，在已启用的自动更新策略、身份、权限、预算、冷却和任务去重约束内自动申请后台更新，无需再点按钮；手动申请是补充入口。关注公司的到期巡检继续走独立调度，普通未访问未关注公司不因过期全部扫描。同步路径不执行搜索、网页读取或模型。
4. 查询新鲜度与事实日期分开：人工资料的基准日不被导入日替代；失败、无关正文或只检查部分主题不能把所有类别更新为新鲜。多人访问复用任务，受预算/冷却阻塞时保留已有结果并显示原因。
5. 研究计划按类别缺口选择主题、保存查询与版本、轮换未检查类别；不把固定“融资/产品”当全公司覆盖。读取按目标类别相关性安排，首页/目录后置；保存内部底稿不等同取得目标证据。总搜索、HTTP、字节、时间硬上限保持，超限记录明确停止原因。
6. 允许在同一任务预算内，根据系统本轮自行发现的内容做有界来源补查；不得注入盲测答案。网页不可读不撤销人工事实；继续其他合法来源。融资沿用专用抽取/比对，其他类别先提供有证据的候选与状态，不预建全部专用分析器。模型/渲染只有确有缺口且调用预算明确时接入，不能绕过访问限制。
7. 交付单位为完整 E4.7 里程碑：资料接收、研究流程、过期访问入队及固定样本验收一起推进，小步提交但普通实现无需逐项再次批准。生产切换前仍提供可审查成果，保留合并部署授权和外部预算闸门。不自动进入 E5、全量联网或收费。

## 验收边界

- 原表每条事件、待核事项及跨公司说明均有可追溯去向；重复不新增，更正追加，冲突定点隔离。无每公司五条限制。
- 固定样本的独立发现与初始资料维护隔离；保留既有失败样本。逐类报告命中数/分母、证据支持、错误归属、重复和费用。试点目标证据支持命中率至少 80%，主体误归属/虚构事实/重复导入新增为零；不事后删除失败样本或当作全网覆盖率。
- 自动测试默认零外部调用。八类工程测试不替代八类真实覆盖；当前表缺少的维度记录待补真实样本，不要求负责人先完成所有公司调研。
- 普通已授权用户访问过期公司可入队，未过期不入队；并发/重复访问合并；未授权拒绝，关闭开关零入队；预算不足/冷却/失败保留旧结果。
