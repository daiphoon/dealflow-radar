# ADR-0017：以“重要变化”作为投资者信息主层

状态：已接受  
日期：2026-08-28

## 背景

授权数据源能够返回工商、股东、风险、知识产权、经营公示和历史变更等资料，但供应商模块只是数据入口，不等于投资者真正需要的产品栏目。把记录数量或静态清单直接平铺，会产生三个问题：重要变化被淹没、普通数量被误解为风险、用户无法看出平台相对原始数据库的增值。

## 决策

1. 投资者主层回答“什么发生了重要变化”，静态资料保留为当前基线和证据详情。
2. 每次受控研究把可比较字段写入版本化 `company_snapshots.summary.structured_research_state`；历史快照不覆盖。
3. 首次研究只建立基线，不生成变化事件。后续使用确定性程序比较前后快照；无变化不产生变化事件，也不调用模型。
4. 只有达到版本化重要性规则阈值的变化才能形成独立事件。低价值变化只随快照保存，不占用投资者时间。
5. 股东分页不完整时，不得根据“本页消失”推断股东退出；只有前后两次均为完整清单时才允许判断新增或退出。相同股东在两次可见快照中的持股比例变化可以直接比较。
6. 工商登记持股比例属于公司股东结构，与基金或用户持有该公司的投资比例严格分离。
7. 工商历史详情默认展示最近同一批次变更；程序仍保留授权缓存和结构化比较状态。
8. “人员相关风险数量”不能说明人员或公司存在投资风险，因此从默认研究模块退出；旧概览在下一次受控重放时撤回。未来只有取得明确任职变化或经核实的人员事件后才进入投资者变化层。
9. 风险接口仅返回数量变化时，只能形成带明确警告的待核实线索，不能自动标记风险严重程度。
10. 变化事件必须保留前值、后值、规则版本、证据引用和原始授权记录血缘；不复制或公开系统受限原文档。

## 程序与模型边界

- 程序负责身份、精确数值、前后比较、去重、权限、证据和重要性规则。
- 后续分析 Agent 只处理已经通过程序验证的中高重要性变化，解释“为什么值得关注、可能影响什么、还不确定什么”。
- Agent 输出不能修改原始数值、补写缺失事实或代替证据；同步公司页面不得调用模型。

Agent V1 使用独立的 `investor_change_analyses` 派生记录，不改写事件和证据。只有 `published + platform_shared + deterministic_change` 且达到重要性门槛的事件可入队；模型只接收前值、后值、确定性表述和允许展示的证据摘录。输出必须通过版本化 JSON Schema，证据 ID 必须属于输入，前后值必须原样保留，输入证据中不存在的数字不得出现在解读。未完成、校验失败或超出预算的解读不向普通用户展示。

## 公司详情页编排契约

公司详情页采用“投资者优先”而不是“供应商模块优先”的顺序：

1. 工商主体身份和数据基准时间之后，首先展示近期重要变化；机构投资关系和基础资料不得把重要变化挤到首屏之后。
2. 首次查看默认返回近 90 天内已经核实的 `deterministic_change`；90 天以前的变化仍可按需查看，但不占用首屏。
3. 再次查看优先展示自上次查看以来的新变化；如没有新增，则明确说明，并回顾近 90 天内已有的重要变化，不能把“没有新增”写成“经营正常”。
4. 首屏最多直接展示 3 条变化，先按重要性、再按事件日期排序；其余变化收起但保持可访问。
5. 每条重要变化先用通俗中文说明“这对股东可能意味着什么”，再允许展开查看前后值、可能影响、不确定性、后续观察和证据。
6. 模型解读存在时可以置于事实详情之前，但必须与事实、证据和免责声明保持可区分；模型未生成时仍展示确定性变化，页面访问不得同步调用模型。
7. 待核实线索与已核实变化分区并默认收起；基础资料按事件类别归档到页面下方，默认不展开。
8. 查看水位只属于当前个人；平台共享变化可复用，基金投资金额、内部估值、机构资料和私有线索继续按原权限隔离。

## 兼容与成本

- 复用现有版本化快照、事件、证据和个人查看回执，不新增 PR1 数据表。
- 现有公司、基金、投资叠加、共享事实和 RLS 路径不变。
- 默认研究从六个供应商模块降为五个，减少一次低价值人员概览调用。
- 本决策不触发任何真实天眼查或模型调用；生产开关继续默认关闭。

## 验收契约

1. 首次快照不产生变化事件；相同快照重放保持幂等。
2. 可验证的持股比例或关键工商字段变化生成一条独立、有证据的共享变化事件。
3. 不完整股东分页不能产生退出结论。
4. 低价值知识产权数量变化只归档，不公开为重要变化。
5. 风险数量变化不形成已核实风险结论。
6. 不同租户看到同一平台共享变化，但看不到其他租户投资字段或私有材料。
7. 首次个人查看只返回近 90 天的重要变化，再次查看优先返回个人查看水位之后的新增事件。
8. 公司页面首屏最多直接展开 3 条重要变化，基础资料和待核实线索默认收起，所有证据仍可下钻查看。
