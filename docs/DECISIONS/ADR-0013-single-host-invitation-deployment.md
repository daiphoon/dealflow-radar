# ADR-0013：邀请测试采用上海单机部署与客户端加密异机备份

- 状态：已接受
- 日期：2026-07-21
- 关联：ADR-0005、ADR-0009、ADR-0012

## 背景

M5A 已经在本机验证生产镜像、单一入口、配置预检、数据库就绪、受限应用账户和备份恢复。下一步只面向 5—10 名邀请用户，不需要生产级 SLA；项目负责人希望避免旅行期间购买闲置服务器，并已确认 M5B 使用上海资源、个人主体备案和低成本部署。

腾讯云当前要求用于备案的中国大陆云服务器或轻量应用服务器采用包年包月，累计购买至少三个月且备案期间剩余有效期不少于一个月。因此资源在实际开始备案时再购买，不使用香港临时服务器。[备案云资源要求](https://cloud.tencent.com/document/product/243/18908)

## 决策

1. M5B 邀请测试采用一台上海轻量应用服务器，起步目标为 2 核 4GB、80GB 以上磁盘；最终套餐和价格只在购买时复核，不写死在代码。
2. FastAPI、Next.js、Caddy 和 PostgreSQL 使用 Docker Compose 部署在同一主机。PostgreSQL 只加入内部容器网络，不发布主机端口；迁移账户与受限应用账户继续分离，RLS 不变。
3. 该拓扑只服务邀请测试，不承诺高可用。数据库、磁盘或整机故障会导致服务暂时不可用；恢复能力依赖异机备份，而不是依赖同机快照。
4. PostgreSQL 自定义格式备份必须先在本机用 `age` 公钥完成客户端加密，再上传到私有腾讯云 COS。生产服务器只保存加密公钥；解密私钥离线保管，不能进入服务器、COS、Git、日志或命令参数。
5. COSCLI 使用独立、最小权限凭据和 `0600` 配置文件，只能写入指定私有存储桶前缀。上传工具拒绝明文 `.dump`，只接受带加密文件校验和与解密后校验值的 `.dump.age`。COS 服务端加密可以作为第二层保护，但不能替代客户端加密。
6. 备份目标保留 14 个每日恢复点和 8 个每周恢复点；实际生命周期规则、上传与下载恢复必须在 COS 创建后验收。应用回滚优先切换旧镜像并保留向前兼容数据库，不直接执行数据库 downgrade。
7. 域名首选 `dealflowradar.cn`，建议同时注册 `dealflowradar.com` 做品牌保护，应用入口计划使用 `app.dealflowradar.cn`。当前仅为候选，不表示已经注册或拥有；购买前必须在注册商再次检查。
8. 域名所有者实名信息必须与个人备案主体完全一致。个人备案仅用于非经营性的邀请验证；不得据此推断网站可以公开收费。M7 商业上线前必须重新完成企业主体、经营性许可、隐私条款和收费模式的合规审查。腾讯云也明确区分非经营性备案与经营性许可，并限制个人备案的服务内容选项。[域名实名与备案区别](https://cloud.tencent.com/document/product/242/8580)、[备案服务内容目录](https://cloud.tencent.com/document/product/243/105730)
9. CloudBase 仍然只负责身份认证。数据库、tenant、基金授权、RLS、业务数据和备份均不迁入 CloudBase。

## 触发升级的条件

出现任一事实后，另立 ADR 评估托管 PostgreSQL 或多机部署：

- 单机故障或维护窗口已经影响邀请测试；
- 数据恢复目标无法由每日异机备份满足；
- 数据量、并发或后台任务持续造成资源争用；
- 正式收费、外部机构合同或 SLA 要求更高可用性；
- 运维人工成本高于托管数据库增量费用。

## 兼容、回滚与限制

- 本决策不修改数据库模型、迁移、业务 API、权限或当前本地试运行数据。
- `compose.production.yml` 继续保持通用；单机数据库通过独立 Compose 覆盖文件叠加，未来切换托管 PostgreSQL 不需要重写应用。
- 本地和 CI 只能验证拓扑、加密失败关闭、明文拒绝和假 COSCLI 调用，不能证明真实域名、证书、COS 权限、生命周期、告警、重启恢复或异机下载恢复已经可用。
- M5B 只有在真实上海环境完成上述人工验收和四类 CloudBase 账户权限回归后才能关闭；此前不得邀请外部用户。
