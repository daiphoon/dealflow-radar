# ADR-0005：公开事件与基金内部投资数据隔离

- 状态：已接受
- 日期：2026-07-13

## 背景

同一未上市公司可能被多个基金投资。公司公开事件可以复用，但投资金额、持股比例、内部估值、MOIC、TVPI 和协议材料属于基金高敏信息。

## 决定

共享公司身份及许可允许的公共事件；每笔投资单独带 `tenant_id`、`fund_id` 和 `visibility_scope=fund`。访问同时受 RLS、基金授权、角色和字段遮罩控制。公司公共快照禁止包含基金私密字段；授权投资概览在响应层单独拼装并审计。

## 影响

可避免重复采集公开事实并阻断跨基金推断；代价是 API 和缓存必须区分公共层与授权叠加层。详细控制见[安全合规](../07-security-compliance.md)。
