# 09 界面与报告线框

## 1. 信息架构

主导航：公司、变化、风险、审核、周报、数据质量、成本；右上角显示当前租户、基金范围和用户角色。所有页面共用新鲜度标签、基准时间和权限提示。同步页面只读取数据库。

| 页面 | 首要问题 | 默认内容 |
| --- | --- | --- |
| 登录页 | 我能否安全进入？ | 私有访问说明、登录、失败不泄露账户存在性 |
| 公司列表 | 哪些公司值得先看？ | 关注、最近变化、风险、新鲜度、信息缺口 |
| 公司详情 | 目前有哪些可核事实？ | 快照、授权投资概览、事件、指标、证据 |
| 自上次查看以来 | 我错过了什么？ | 新增、纠正、撤回与风险级别 |
| 风险中心 | 哪些事项需行动？ | 高/极高风险、审核状态、来源冲突 |
| 事件时间线与证据 | 结论从哪里来？ | 时间语义、来源、证据片段、版本轨迹 |
| 人工审核中心 | 哪些候选需决定？ | 触发规则、主体候选、原文、决定与理由 |

| 投资组合周报 | 本周组合发生什么？ | 重大变化、风险、无变化说明、信息缺口 |

## 2. 公司列表

```text

公司            最近实质变化      风险      新鲜度       最后检查      信息缺口
虚构公司 A      2 条 / 3 天内      高        stale       14 天前       财务数据
虚构公司 B      无新增公开信息     低        fresh       2 天前        股权口径
```

“无新增公开信息”旁显示检查范围和时间，不显示“经营正常”。点击更新先弹出 `dry-run` 估算；过期页面仍可立即打开。

## 4. 变化、风险与时间线

“自上次查看以来”基于每用户/公司查看水位，分为新增、纠正、撤回和后续进展；用户可将水位更新到当前事实版本。风险中心默认按 `critical/high`、未审核、发生时间排序，并单独显示身份歧义和来源冲突。

事件详情展示：`occurred_at`、`published_at`、`observed_at` 的明确标签；五项独立评价及组成因素；最小证据片段；原始来源链接或受控存储引用；相关事件；审核和纠错轨迹。不得只显示综合颜色分。

## 5. 审核中心

```text
[高风险优先] [身份歧义] [来源冲突] [低置信度]
候选事实                   主体候选          证据/来源       触发规则
---------------------------------------------------------------
事实与不确定性 | 来源 A/B/C... | 金额单位检查 | 相似既有事件
[通过发布] [纠正后发布] [驳回] [保持待审]
决定理由（必填）                           [确认]
```

严重负面确认框明确提示法律状态和发布范围。审核员无基金授权时看不到投资金额、内部估值等字段。

V1 已实现本机最小工作台：待审优先展示公司、候选事实、三类时间、五项独立评价、证据、不确定性和触发规则；事件可填写理由并确认核对后批准或驳回，历史决定继续展示。实体提及歧义仅只读提示，不提供直接批准。纠正后发布、撤回、保持待审、筛选排序和专用身份解析尚未实现。工作台默认关闭，正式认证前不得公开部署。

## 6. 数据质量与成本

数据质量页按身份、工商、新闻、司法、融资、指标分类显示最后检查、TTL、覆盖来源、冲突和缺口；`unknown` 与 `stale` 分开。成本页显示预算消耗、预计/实际费用、缓存命中、无变化任务、搜索有效率、模型校验成功率、人工审核量、每家公司和每条有效事件成本。价格为配置版本，不能暗示实时供应商报价。

## 7. 固定模板报告

公司即时报告：身份和新鲜度 → 授权投资概览 → 本期重大变化 → 分类事实 → 指标历史 → 风险与待审 → 来源与缺口。组合周报：摘要 → 重大积极动态 → 重大风险 → 退出进程 → 需人工行动 → 覆盖与成本。

第一版输出 HTML/Markdown。每份报告显示模板版本、事实水位、`as_of_date` 和生成时间；事实无变化不重建。模型评论若未来启用，必须放在独立“分析意见”区并明确“非事实、非投资建议”。

## 8. 关键交互状态

- `fresh`：正常展示，不入队。
- `stale`：顶部提示“展示最近一次结果”，允许后台申请更新。
- `refreshing`：展示已有任务进度，不创建重复任务。
- `budget_deferred`：说明预算阻塞，仍展示旧数据。
- `unresolved`：展示身份待确认，严重负面候选不进入公开时间线。
- `no_reliable_data`：显示固定缺失文案，不生成推测值。
