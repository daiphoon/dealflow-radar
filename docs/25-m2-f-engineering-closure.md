## 修改与复用

1. 获取政策及审计见 [ADR-0029](DECISIONS/ADR-0029-public-source-acquisition-policy.md)。
   默认 enforce；公开 HTTP advisory 需要明确政策和路线，访问控制与预算不放宽。
2. 合同/租赁/框架及产品批准/准入动作形成有原文支持的 typed matter；编号融资轮次
   保留其完整口径。主体、轮次/日期及明确交易不同阶段不能因相同措辞被合并。
3. 抽取、验证、比较和 prompt 分别版本化；真实新模型效果没有在本轮验证。
4. `prepare_pending_research_requests(reference_at=...)` 把明确参考值传入实际 job/
   query plan，模型输入保留同一参考字段。任务时间和心跳继续用真实时钟。
5. 评价适配逐输出关联裁决，分别记录抽取正确、证据支持、确认和交付；正式 scorecard
   汇总语义不变，不能从 published 行数反推零命中。
6. `scripts/research_validation_contract.py` 是隔离实验适配，核对实际 checkout、已加载
   模块、身份/配置/顺序/参考口径，并提供绑定合成用户/租户/公司的白名单状态投影。
   无公共写 API，不接生产，不携带正文、查询或 benchmark。
7. 九种同库研究情境复用现有 completion/API/report；不再增加第二套状态判断。
   隔离 D 没有 B 状态属于 harness gap。补齐访问控制和限流的 API/报告/组件反馈。
   过去运行记录与旧报告不回写。
