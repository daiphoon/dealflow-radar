# 00 产品需求

## 1. 产品定义

“原始股雷达”是私有投后信息监测平台，不是传统搜索引擎。系统在后台按需更新并低频巡检，将公开或经授权资料转为可追溯的事件、指标和快照；用户查询时只读取数据库，不同步搜索、不调用大模型。

初始资料可以来自负责人用 ChatGPT、Gemini 等工具研究后亲自复核的表格。已明确确认的身份和普通业务资料经格式、重复与真实冲突检查即可按人工确认依据准入，不要求逐家重新查询政府或商业数据库。用户申请更新时先看到已有内容，再在已授权预算、冷却和权限内及时启动或复用后台网络研究，完成后显示必要新增、更正和来源缺口。方向见 [ADR-0022](DECISIONS/ADR-0022-curated-baseline-and-incremental-research.md)；表格适配与新准入路径尚待 E4 实现，不能视为已上线。

目标用户：基金有限合伙人、直接持股的原始股东、投后管理人员；未来可扩展到财富管理机构、家族办公室和受授权专业顾问。

## 2. 要解决的问题

1. 数百至数千家公司信息分散、更新时间不一，人工重复搜索成本高。
2. 未上市公司财务披露有限，事实、估算和传闻容易混淆。
3. 重大变化需要证据、主体匹配和确定性风险闸门；身份歧义才强制人工处理，不能只给不可解释的 AI 摘要。
4. 同一公开事件可被多个基金使用，但内部投资数据必须隔离。
5. 搜索、模型、商业数据和人工审核成本必须能预算、归因和暂停。

## 3. 核心用户任务

| 用户任务 | 最小可接受结果 |
| --- | --- |
| 浏览公司 | 显示最近已发布快照、基准时间、新鲜度和信息缺口 |
| 录入初始资料 | 负责人确认资料先预览后导入；保留出处、日期口径和人工确认记录，原待核事项保持线索 |
| 查看变化 | 基于用户上次查看时间列出新增或纠正事件，不临时生成 |
| 复核风险 | 查看事件原文元数据、最小证据片段、来源等级和审核轨迹 |
| 查看投资 | 仅有基金授权时显示金额、持股、内部估值等私密字段 |
| 主动更新 | 立即返回旧数据；满足预算、冷却和去重后创建后台任务 |
| 审核候选 | 通过、驳回、纠正或撤回，并记录审核人、时间和理由 |
| 获取报告 | 用固定模板从结构化数据生成 HTML/Markdown 公司报告或周报 |
| 查看成本 | 按租户、公司、任务、Provider 和有效事件查看费用与产出 |

## 4. 功能范围

- 公司、别名、主体关系、基金和投资关系管理。
- 原始文档、实体提及、事件证据、指标观测和快照的分层数据链路。
- 融资股权、重大合同、经营财务、产品技术、治理人员、法律合规、产能资产、退出流动性和信息质量事件。
- 公司身份解析、文档与事件去重、自动发布风险闸门、身份例外审核和纠错撤回。
- 关注、TTL、动态升降频、任务合并、冷却、预算延迟和 `dry-run`。
- JSON/CSV/Excel/Markdown 研究结果导入；身份通过后由版本化规则自动发布或保留为未确认线索。
- 固定模板报告、风险中心、审核中心、来源覆盖和成本仪表盘。

详细对象见[领域模型](01-domain-model.md)，页面见[界面线框](09-ui-wireframes.md)。

## 5. 新鲜度语义

- `fresh`：未超过该数据类别的有效 TTL。
- `stale`：已过 TTL，但仍可返回最近已发布数据并尝试后台入队。
- `refreshing`：已有同公司更新任务，禁止重复创建。
- `unknown`：从未成功检查或身份尚未解析。
- `budget_deferred`：预算不足；读取功能不受影响。

“未发现新的公开信息”只描述本次检查结果，绝不等同于“公司经营正常”。

人工整理基准时间、系统导入时间和网络最后检查时间分别显示；初始资料已确认而系统尚未联网检查时，内容仍可读取，不因 `unknown` 或链接受阻变成空页面。今天导入不表示资料已检查至今天。

## 6. 报告与专业顾问边界

普通报告由已发布事件、指标、快照、证据元数据和信息缺口按固定模板生成。可选模型评论必须独立标注、缓存、版本化并关联证据，不进入同步查询链路。

专业顾问升级只做架构预留：用户提出深度问题后形成私有任务单，管理员确认范围、权限、价格和时效；顾问可用高级数据源研究并人工审核。顾问分析默认只对任务授权人可见；其中可复用的公开事实只有在脱敏、来源许可、身份解析和审核全部通过后，才能另行写入公共事件层。

## 7. Demo 非目标

本阶段及近期 Demo 不做全网每日扫描、同步 AI 问答、自动估值、移动 App、PDF 优先、完整计费、微服务、Redis/Celery/Kafka/Kubernetes、独立向量数据库、绕过访问限制或真实基金数据公开演示。

## 8. 成功指标

- 已发布事件证据关联率为 100%。
- 同一文档、事件和活跃更新任务重复率为 0。
- 同步公司查询的外部调用数为 0。
- 严重负面自动升级为已确认事实数为 0。
- 无变化任务触发 LLM 数为 0。
- 每条有效事件、每家活跃公司月成本可计算并可归因。
- 私密基金字段的越权读取测试全部拒绝。
